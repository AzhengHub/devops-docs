# Linux 系统部署后初始化

本文汇总 Linux 主机部署完成后的常见初始化操作，适用于需要统一基础环境的测试、开发或已具备边界防护的服务器。执行前请确认已通过控制台或 SSH 密钥保留登录途径，并按实际安全策略调整。

> 关闭 SELinux、防火墙或自动更新会降低系统的默认防护能力。生产环境应优先配置规则、集中补丁管理和变更窗口，而不是直接关闭这些功能。

## 通用配置

### 设置上海时区

使用 `timedatectl` 设置时区：

```bash
sudo timedatectl set-timezone Asia/Shanghai
timedatectl
```

若系统未安装或不支持 `timedatectl`，可改为更新 `/etc/localtime`：

```bash
sudo ln -snf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
date
```

### 使用 24 小时制显示时间

命令行脚本建议直接指定格式，避免受用户语言环境影响：

```bash
date '+%F %T'
```

如需为系统默认语言环境指定 24 小时制，可设置 `LC_TIME`。`en_DK.UTF-8` 采用 24 小时制；先确认该 locale 已生成：

```bash
locale -a | grep -i '^en_DK\.utf8$'
```

Ubuntu/Debian：

```bash
sudo locale-gen en_DK.UTF-8
echo 'LC_TIME=en_DK.UTF-8' | sudo tee -a /etc/default/locale
```

RHEL 系列：

```bash
sudo localectl set-locale LC_TIME=en_DK.UTF-8
```

重新登录后生效；桌面环境可能还需要重新登录图形会话。

## CentOS / RHEL 系列

以下操作适用于 CentOS、RHEL、Rocky Linux、AlmaLinux 等使用 SELinux 和 firewalld 的系统。

### 关闭 SELinux

先检查当前状态：

```bash
getenforce
sestatus
```

临时切换为宽容模式（重启后会恢复）：

```bash
sudo setenforce 0
```

如确实需要永久关闭，修改配置并重启系统：

```bash
sudo sed -ri 's/^SELINUX=(enforcing|permissive)$/SELINUX=disabled/' /etc/selinux/config
grep '^SELINUX=' /etc/selinux/config
sudo reboot
```

> 若配置文件中使用了其他值或已被注释，请手动将 `SELINUX=` 设置为 `disabled`。生产系统更推荐保留 SELinux，并按应用需求编写策略或使用宽容模式排障。

### 关闭 firewalld

确认服务存在且已启用：

```bash
systemctl status firewalld
```

停止服务并取消开机启动：

```bash
sudo systemctl disable --now firewalld
systemctl is-enabled firewalld
systemctl is-active firewalld
```

如仅需开放服务端口，建议保留 firewalld 并添加规则，例如：

```bash
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --reload
```

## Ubuntu / Debian 系列

### 关闭自动更新定时任务

先查看自动更新配置和定时器状态：

```bash
cat /etc/apt/apt.conf.d/20auto-upgrades
systemctl list-timers 'apt-daily*'
```

将 `/etc/apt/apt.conf.d/20auto-upgrades` 中的自动更新配置由 `"1"` 改为 `"0"`，并停止、禁用相关定时器：

```bash
sudo sed -i 's/"1"/"0"/g' /etc/apt/apt.conf.d/20auto-upgrades 2>/dev/null
sudo systemctl disable --now apt-daily.timer apt-daily-upgrade.timer
```

验证配置：

```bash
cat /etc/apt/apt.conf.d/20auto-upgrades
systemctl is-enabled apt-daily.timer apt-daily-upgrade.timer
```

`20auto-upgrades` 在部分最小化镜像中可能不存在；上述命令会忽略该文件不存在的错误，但仍会尝试禁用定时器。关闭后请建立人工或集中式补丁流程，避免长期遗漏安全更新。

### 防火墙说明

Ubuntu 常见的防火墙管理工具是 UFW。若需要停用它：

```bash
sudo ufw disable
sudo ufw status
```

若 UFW 未安装，`ufw` 命令会不可用；可用 `sudo apt install ufw` 安装后再按需配置。

## 初始化完成后的检查

```bash
# 时区与本地时间
timedatectl

# 默认语言环境和时间格式
locale
date '+%F %T'

# RHEL 系列：SELinux 与 firewalld
getenforce 2>/dev/null || true
systemctl is-active firewalld 2>/dev/null || true

# Ubuntu/Debian：apt 自动更新定时器
systemctl is-enabled apt-daily.timer apt-daily-upgrade.timer 2>/dev/null || true
```
