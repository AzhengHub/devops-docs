## 为 kubectl 配置 tab 键补全
```sh
# 安装基础补全包
apt-get update
apt-get install -y bash-completion

# 为 kubectl 配置 tab 键补全
kubectl completion bash >> /etc/profile.d/kubectl_completion.sh

# 使配置生效
source /etc/profile.d/kubectl_completion.sh

# 输入 kubectl 后按 tab 键验证补全是否生效
```
